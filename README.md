# Madhu Priya Mareddy: Portfolio

Accessible portfolio built with React, TypeScript, and Vite.

## Run locally

    npm install
    npm run dev

## Build

    npm run build
    npm run preview

## Edit content

- `src/data/profile.ts`: name, headline, experience, contact links
- `src/data/projects.ts`: project cards (only list claims you can explain)

## Accessibility

- Skip link, semantic landmarks, and labelled sections
- Visible focus indicators
- Respects `prefers-reduced-motion` and light/dark color schemes
